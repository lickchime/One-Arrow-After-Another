# 一箭又一箭 (One Arrow After Another)

## 项目名称
一箭又一箭 (One Arrow After Another)

## 游戏简介
一个基于 Python 和 Pygame 的益智休闲小游戏。游戏盘面由网格和四种方向（上、下、左、右）的箭头组成。玩家需要点击箭头，使其沿着箭头的方向飞出棋盘。如果箭头前进方向上没有其他箭头阻挡，它就会飞出并消除；如果被挡住，则无法消除并消耗一次失误机会。清空所有箭头即可过关，失误用尽则失败。

## 开发环境
- 操作系统：Windows 10/11
- 编程语言：Python 3.13
- 游戏库：Pygame 2.6.1
- IDE：VS Code

## 安装和运行方法
1. 确保电脑已经安装了 Python（推荐 3.8 以上版本）。
2. 安装 Pygame 库：在终端输入 pip install pygame -i https://pypi.tuna.tsinghua.edu.cn/simple
3. 运行游戏：在终端输入 python One_Arrow_After_Another.py

## 游戏操作说明
- 鼠标左键：点击盘面上的箭头，尝试让其飞出棋盘。
- R 键：重新开始当前关卡。
- 空格键 / 回车键：在通关或失败界面，进入下一关或重玩本关。
- ESC 键：退出游戏。
